# Capstone_1: Sales Analysis
This project grew my skills in analyzing retail sales data using MySQL to identify trends, performance metrics, and insights 
that can help improve business decisions. The analysis focuses on my assigned sales territory which is under Sales Manager
See Ellefson, which includes the East region in the state of New York. Using SQL queries I examine total revenue, monthly 
sales trends, product category performance, and store level performance. The main goal is to provide insights that can help 
optimize sale strategies and improve the overall performance within the territory. The results of this analysis is visualized 
with using Excel pivot tables and charts. 

Technologies used: MySQL, Excel, Github
